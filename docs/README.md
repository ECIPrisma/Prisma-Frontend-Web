# Documentación Oficial del Proyecto PRISMA (Frontend)

Este directorio contiene los documentos oficiales aprobados para la entrega académica y técnica de la plataforma PRISMA (Cliente Web SPA React & Cliente Móvil Android):

1. **[Documento de Arquitectura FrontEnd PRISMA.pdf](./Documento%20de%20Arquitectura%20FrontEnd%20PRISMA.pdf)**:
   - Especificación de arquitectura y diseño de interfaces de usuario.
   - Matriz de pantallas y permisos de acceso por rol (Tendero, Proveedor CPG, Repartidor, Administrador).
   - Diagrama de flujo de navegación entre vistas.
   - Tecnologías utilizadas (React 19, Tailwind CSS, Vite, Android Kotlin SDK 34).
   - Evidencias visuales reales de implementación (Portal Web y App Móvil).

2. **[Documento de Manual de Identidad PRISMA.pdf](./Documento%20de%20Manual%20de%20Identidad%20PRISMA.pdf)**:
   - Guía completa de identidad visual de marca PRISMA.
   - Logotipo oficial, isotipo, variantes cromáticas y zonas de exclusión.
   - Sistema tipográfico institucional y jerarquías.
   - Paleta de color corporativo y tokens del sistema de diseño.

3. **[Manual de Identidad PRISMA (Diapositivas).pdf](./Manual%20de%20Identidad%20PRISMA%20(Diapositivas).pdf)**:
   - Presentación ejecutiva de la identidad visual y sistema de diseño.

4. **[Informe Final Proyecto PRISMA IEEE.pdf](./Informe%20Final%20Proyecto%20PRISMA%20IEEE.pdf)**:
   - Informe formal de culminación de proyecto bajo el estándar de publicación IEEE.
